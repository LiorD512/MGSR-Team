Persona Network · Men Platform · Redesign Study

Scout Agents, rethought.

The current screen groups every pick by country and prints a flat list — so you scroll through 44 countries and never learn why any player is there. These three concepts all answer one question first: “why am I looking at this player, and should I act now?” Pick a direction (or mix them) and I'll build it for real.

What's wrong today

  • Country sections dominate — reason to sign is buried
  • Flat list, no ranking — all players feel equal
  • No match score surfaced — the 0–100 signal is hidden
  • FM potential, contract leverage never shown
  • No "act now" urgency — nothing tells you what's hot
  • Images often missing → rows look broken

What these concepts fix

  • Reason-first: the profile type leads every card
  • Ranked by match score so the best float up
  • Rich signals: FM gap, contract months, value delta
  • "Why now" one-liner on every player
  • Country becomes a filter, not the whole structure
  • Graceful initials avatar when no photo exists
Concept A

Signals Inbox

A triage queue. The top row is why players surfaced — each scouting profile type is a filter tile with a live count. Click one and the list below shows just those opportunities, ranked by match score. Country is a flag chip inside each row, not a section header. Built for fast daily triage: scan reasons, sign or dismiss.

Answers “why is this player here” in the first glance Reason tiles = instant daily triage Feedback (👍/👎) trains agents in-line
