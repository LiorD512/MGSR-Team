How the switch behaves

  • One tap re-skins the room. Accent colour goes red for Men, warm gold for Youth — every accent (badge, nav counts, breadcrumb pill, avatar, headline) follows.
  • Data scope swaps, chrome stays. Same navigation, same layout — the roster, portfolio value, counts and the active window change to match the selected platform.
  • Always-visible context. The current platform sits pinned at the bottom of the rail and as a pill in the breadcrumb, so there is never doubt which platform is live.
  • Women platform intentionally omitted for now — the menu is built to add it later as a third tile without any layout change.
