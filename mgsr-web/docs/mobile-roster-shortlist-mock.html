What this concept changes

▦

Two players per row. The roster gallery and shortlist board go from a single tall column to a 2-up grid, so you see ~4× more players per screen. Cards shrink gracefully (portrait roster cards, compact media+body shortlist cards).

⚙

Filters & sort move into a bottom sheet. The long always-open filter tray (search + position + selects + chips + region + sort) is replaced by a compact bar: search, a Filter button with an active-count badge, and a sort button. Everything opens in a swipe-up sheet.

◉

Active filters stay visible. A scrollable chip strip shows exactly what's applied (position, flags, sort) and lets you clear each — so the controls collapse without hiding state.

↕

Sticky search + density toggle. Search stays pinned while scrolling, and a Grid/Ledger toggle lets power users switch back to the dense table.
